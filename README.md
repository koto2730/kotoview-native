# kotoview

> **Note**  
> このアプリは、kotoviewのネイティブ動作を試すRust版をつくってみたものです。リポジトリ名は `kotoview-native` ですが、アプリ実行コマンドは `kotoview` になります。

Rust (`eframe` / `egui`) で構築された、軽量・高速なローカルメディアビューアーです。  
通常のフォルダに加え、**ZIP 書庫内の画像や動画を解凍せずに直接閲覧・管理**できます。

---

## 主な特徴

- **フォルダ & ZIP 書庫対応**:
  - ローカルフォルダおよび ZIP ファイルをそのまま閲覧可能。
  - ZIP 内のファイル削除は書庫を破壊せず、サイドカーファイル (`.trash.json`) による論理削除として安全に処理。
- **画像 & 動画のサポート**:
  - 画像: JPEG, PNG, GIF, WebP, BMP, AVIF（拡大縮小・回転・反転表示に対応）。
  - 動画: MP4, WebM, MOV, MKV, AVI（`ffmpeg` を使用した先頭フレーム自動サムネイル生成、プレビューおよび外部プレーヤー/ブラウザ連携再生）。
- **2 つの表示モード**:
  - **フォルダビュー**: 階層構造を辿ってブラウズ。
  - **一覧モード (Flat View)**: 指定階層 (`depth`) までのメディアをフラットに一覧表示。
- **最適化されたキャッシュ機構**:
  - メモリ (GPU テクスチャ) とディスクの 2 系統キャッシュにより、大量ファイルでも軽快に描画。
  - JPEG の DCT スケールデコードによる省メモリ・高速サムネイル生成。
- **非破壊ファイル操作**:
  - 削除機能: ローカルフォルダでは `.trash` サブフォルダへ安全に退避。
  - エクスポート機能: 指定したメディアを任意の場所へ書き出し。

---

## 必要環境

- **Rust**: 2024 edition 対応ツールチェーン (1.85+)
- **FFmpeg**: 動画サムネイル生成時に使用します。システムの `PATH` に `ffmpeg` コマンドが設定されている必要があります。

## ビルド・実行方法

### 開発実行
```bash
# アプリケーションの起動
cargo run --release

# フォルダや ZIP を引数で直接指定して起動する場合
cargo run --release -- path/to/media_or_archive.zip
```

### バイナリのビルド
```bash
# 最適化バイナリの生成
cargo build --release
```

## 操作一覧・ショートカットキー

### グリッド一覧画面
| 操作 | アクション |
| :--- | :--- |
| **アイテムクリック** | フォルダ移動 / ビューアー起動 |
| **動画右クリック** | OS 既定アプリで開く / ブラウザで開く |

### ビューアー画面
| キー | アクション |
| :--- | :--- |
| `Esc` / `q` | グリッド画面へ戻る |
| `←` / `→` | 前のメディア / 次のメディアへ移動 |
| `Space` | 動画の再生（OS 既定プレーヤーで起動） |
| `[` / `]` | 左 90 度回転 / 右 90 度回転（画像のみ） |
| `f` | 左右反転（画像のみ） |
| `Enter` | ファイルのエクスポート（保存先ダイアログ表示） |
| `d` / `Delete` | ファイルの削除確認ダイアログ表示（`.trash` へ移動） |
